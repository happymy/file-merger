# File Merger Pro

一键将整个目录（含子目录）的所有文件合并为 Markdown 文件，专为「白嫖」Web 端 AI 编程而生。

当你需要让 ChatGPT/Claude/Gemini 等网页版 AI 帮你阅读或修改整个项目时，手动复制粘贴太痛苦。
这个工具能自动扫描目录，按相对路径生成带标题的 Markdown，支持排除规则、压缩、大文件自动拆分，并可直接粘贴到 AI 对话框。

## ✨ 功能特性

📁 **递归扫描目录**：将用户选择的文件夹及其所有子文件合并成一个 .md 文件。

📝 **自动生成标题**：每个文件以 ## 相对路径/文件名 开头，代码块自动识别语言。

⚙️ **图形化排除规则**：
- 支持目录排除和文件排除（glob 模式，如 node_modules、*.log）。
- 可拖拽文件夹/文件到标签容器自动生成排除建议。
- 每个规则可单独启用/禁用。

🚫 **二进制文件处理**：可选择排除二进制文件或显示文件大小占位。

📦 **压缩输出**：去除代码块语言标记、多余空行和空格，减少 Token 消耗。

✂️ **智能拆分**：当合并后字符数超过设定阈值时，自动按文件边界拆分为多个部分。
- 每个部分（除最后一个）可追加自定义"待续"提示（如 请先阅读，等我继续输入。）。
- 预览区使用选项卡切换各部分，支持一键复制当前部分到剪贴板。

🏷️ **自定义尾部**：可在文件末尾追加自定义内容（如 检查代码错误、业务逻辑和安全审计。）。

💾 **保存灵活**：单文件/多文件保存；文件名支持时间戳和文件夹名占位符；保存后自动打开所在文件夹。

🎨 **深色主题**：自动跟随系统明暗模式。

🌐 **中英文界面**：一键切换。

🔄 **历史记录**：记住最近使用的 8 个目录。

_THREADS **多线程处理**：使用 Worker 避免界面卡顿，实时显示进度。

## 📦 安装

确保已安装 Node.js (版本 ≥ 16)。

克隆或下载本项目代码。

在项目根目录执行：

```bash
npm install
npm start
```

## 🚀 使用指南

### 1. 选择工作目录
点击 "选择目录" 或将文件夹拖拽到上方区域。
工具会自动读取该目录下的配置文件（.file-merger-config.json），若无则使用默认设置。

### 2. 配置排除规则
- **手动添加**：在输入框中填写 glob 模式（如 node_modules、**/test/**、*.log），点击 添加 或按回车。
- **图形选择**：点击 📁 浏览 或 📄 浏览，从文件夹/文件对话框中选择要排除的目录或文件，工具会自动生成相对于根目录的 glob 建议。
- **拖拽添加**：将文件/文件夹拖拽到对应排除容器即可。
- **启用/禁用**：点击标签左侧的复选框可临时关闭某条规则而不删除。

### 3. 设置合并参数
- **白名单扩展名**：只包含指定扩展名的文件（如 js,ts,json,md），留空则全部包含。
- **文件大小上限**：跳过大于指定 KB 的文件。
- **排除二进制文件**：勾选后二进制文件直接跳过。
- **忽略隐藏文件/文件夹**：忽略以 . 开头的文件或目录。
- **压缩输出**：启用后去除代码块语言标记、连续空行等，进一步减少字符数。
- **每段最大字符数**：当合并后总字符数超过此值时，自动拆分为多个部分。建议设置为网页 AI 输入框的字符限制（如 ChatGPT 约 8000-10000 字符，Claude 可设 80000 字符）。
- **分段尾部内容**：若拆分为多段，则在前 n-1 段的末尾自动添加此内容。建议填写 "请先阅读，等我继续输入。" 或类似提示，让 AI 知晓后续还有内容。
- **自定义尾部内容**：追加在整个合并文档的最末尾。建议按实际需求填写，例如 "检查代码错误、业务逻辑和安全审计。" 或其它指令。

### 4. 扫描与预览
点击 "🔍 扫描并预览"，工具将扫描目录并生成合并后的 Markdown。

若启用了拆分，预览区上方会出现多个选项卡（如 分段 1 (8000 字符)），点击切换。

点击 "📋 复制" 可将当前显示的文本复制到剪贴板，然后粘贴到 AI 对话框。

预览无 200 行限制，直接显示完整内容（拆分部分可逐个查看）。

### 5. 保存合并结果
点击 "💾 合并并保存"：
- 若未拆分：弹出保存对话框，默认保存为 merged-时间戳.md（可自定义模板）。
- 若已拆分：弹出保存目录选择框，所有分段将以 merged-part1.md、merged-part2.md … 的形式保存到该目录。

## 🧠 最佳实践（白嫖 AI 编程）

### 将项目合并为 Markdown 并拆分
1. 设置每段最大字符数为你使用的网页 AI 输入框限制（例如 ChatGPT 约 8192 字符，Claude 可设 80000）。
2. 分段尾部填入 请先阅读，等我继续输入。 让 AI 理解内容尚未结束。

### 粘贴到 AI
1. 从预览区复制第一部分粘贴到 AI 对话框。
2. 等 AI 回复后，将第二部分内容粘贴，重复直到全部输入。

### 给 AI 下达任务
在发送第一段之前，可在自定义尾部添加任务指令，如：
```
阅读以上所有代码，检查代码错误、业务逻辑和安全漏洞，并给出改进建议。
```
或要求 AI 修改某文件、生成新模块等。

### 保存 AI 回复
如果 AI 返回的内容较长，可先复制到本地文件保存，然后使用"通义灵码"或其它 IDE 工具应用更改。

为方便应用，可在提示中加入 "按照上述内容生成文件"，让 AI 直接输出可写入文件的完整代码。

## 📂 项目结构

```
file-merger-pro/
├── package.json
├── main.js            # Electron 主进程
├── preload.js         # 预加载脚本（安全暴露 API）
├── worker.js          # Worker 线程（扫描、读取、编码）
└── renderer/
    ├── index.html     # 界面
    ├── style.css      # 样式（含深色主题）
    └── renderer.js    # 渲染进程逻辑
```

## ⚠️ 注意事项
- 配置文件 .file-merger-config.json 会保存在所选目录的根下，可随项目共享。
- 二进制文件默认不嵌入内容，仅显示文件大小占位，若需要查看二进制内容请单独处理。
- 编码检测使用 jschardet + iconv-lite，能处理大多数常见编码，若遇乱码可手动转换后重新合并。
- 路径校验严格：排除规则必须位于根目录内，无法通过 ../ 向上穿越。
